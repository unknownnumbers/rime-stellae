# Rime Stellae 使用說明

## 安裝

從[發布頁](https://github.com/unknownnumbers/rime-stellae/releases)下載安裝包並執行. 安裝器需要 Windows 提升權限來註冊輸入法. 安裝完成後, 使用 Windows 輸入法切換鍵選取墨芯.

首次安裝預選 TC 註冊, 可在安裝選項選擇 SC. 升級保留已存選擇. 介面語言與輸入方案的輸出字形分別設定. Windows 註冊所需的實際語言識別碼見[來源索引](SOURCES.md).

程式預設安裝到 `%ProgramFiles%\RimeStellae`. 使用者資料預設位於 `%APPDATA%\RimeStellae`, 已設定自訂位置時使用該位置. 官方 Weasel 與墨芯使用不同服務、登錄身分及預設資料目錄.

## 加入方案

1. 從通知區墨芯選單開啟使用者資料夾.
2. 依所選方案作者的安裝說明加入 schema、詞典及所需依賴. 也可使用隨附的 `rime-install.bat`, 明確指定包名、來源 URL 或本地 ZIP.
3. 在自己的 `default.custom.yaml` 設定 `schema_list`, 並按需要設定方案切換鍵, 然後選擇重新部署.
4. 使用自己設定的切換鍵開啟方案選單. 初始空配置不設定切換鍵.

例如, 把下方的 `your_schema_id` 換成所裝方案的實際 ID. 方案可能需要自己的 Lua、模型、詞典或其他資料, 依其作者說明取得完整依賴. 單獨複製一份詞典不等於已安裝方案.

```yaml
patch:
  schema_list:
    - schema: your_schema_id
  switcher/hotkeys:
    - Control+grave
    - F4
```

手動安裝工具在使用者發起下載時連線到指定來源. 安裝器本身不自動獲取方案. 各方案的來源、授權及額外依賴由其作者說明.

共用資料提供前端外觀、配色預覽、標準 OpenCC、標點、按鍵及符號資源. `weasel.yaml`、`default.yaml` 等標準檔名保留, 使用者修改放在對應 `.custom.yaml` 或方案自有檔案.

## 升級與卸載

升級前備份使用者資料夾. 安裝器更新自身程式目錄, 保留使用者資料及既有選項. 安裝前保存 Windows 輸入項目, 註冊後保留原有其他輸入法及所選墨芯項目.

卸載使用 Windows 已安裝的應用程式入口. 卸載保留使用者資料, 方便之後重新安裝. 已開啟的應用程式可能仍載入舊前端 DLL, 更新後完整退出再重開應用程式.

## 診斷及問題回報

正式構建以 `STELLAE_ENABLE_PROMPT_TRACE=0` 關閉臨時數值診斷. 開發者可由同一來源明確開啟診斷構建, 用於固定測例的問題調查. 引擎及部署工具另有一般執行日誌.

提交 issue 時提供 Windows 版本、應用程式、前端版本及可重現步驟. 分享設定或日誌前, 先移除個人路徑、帳號及實際輸入內容. 本項目尚未設定自動更新來源, 更新請查看發布頁.
