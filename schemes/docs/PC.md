# 墨芯完整方案

從墨芯整合安裝器安裝前端與通用方案. 源碼位於 `config/pc`, 採新裝範例設定, 請先備份已有同名檔案.

中文預設 SC 輸出, 可切換 TC/SC. 中文橫排 5 項, 英文直排 6 項, 日語直排, 均使用非內嵌組字.

中文支援現有全拼、縮寫、容錯、組句與本地學習. 組字中的 `;` 固定前一個完整音節的拼寫及邊界, `"` 確認左側整段完整拼寫; `'` 保持音節分隔用途, Tab 保持導航. 原碼 Return 保留輸入標記, 正常選詞只提交候選文字.

游標在草稿末端時, 若整段自第 8 鍵起只能切分為單字母簡拼, 墨芯使用普通組句. 其他拼寫按原有候選規則查詢. 查字、Unicode 及計算工具按輸入模式調用.

英文支援完整詞、補全、容錯、大小寫與既有縮寫展開. 英文模式的狀態圖標為藍色 En, 由墨芯前端提供. 平假名、片假名、漢字、romaji 與 q/x/v 查詢見 [日語說明](../config/pc/JAPANESE.md). 查字與工具來源見 [來源索引](sources/README.md).

已選詞後, Tab 可回到已選文字與餘碼的邊界, Backspace 優先刪除未選餘碼. `U`、`uU` 和 `cC` 只在整段草稿開頭啟動工具. 中文與英文使用左右 Shift 切換, Ctrl+E 進入日語, Ctrl+R 返回中文. 墨芯的 Ctrl+Space 取消草稿並切換紅 A.

## 可選詞彙

通用方案可直接使用. 可選模組為 `math`、`physics`、`computer` 及 `poetry`. 數學及物理包提供廣泛學科詞彙, 詩詞包遍歷固定來源的全量唐詩、宋詩、宋詞及配套選集.

先更新至 2026.11.14.2 或更新的方案基座, 再將所需模組 ZIP 解壓至用戶資料夾, 使檔案位於 `rymcp_dlc/<id>/`, 然後重新部署. 保留包內全部檔案. 更新模組時替換該模組的完整目錄; 卸載時刪除該目錄並重新部署. 已學習的詞仍可由用戶詞庫提供, 學習資料不隨模組刪除.

部署時由 Rime 編譯詩詞等可選詞表. 數學、物理與電腦的英文拼寫糾錯使用隨模組提供的索引. 舊版模組可下載新版後原位更新並重新部署. 詳見 [DLC 來源與限制](dlc-sources.md).

## 更新與合併

保留用戶學習庫. 已有 `default.custom.yaml`、`weasel.custom.yaml`、`rime.lua` 或同名方案自訂時, 先備份並對照新範例合併. 同名自訂可能覆蓋新預設, 重新部署後核對方案清單、Lua 入口與候選布局.
