# Rime Stellae / 墨芯

> 本项目由人类与 AI 协作产生. 部分 AI 提出的内容可能尚未经人工审核. 若有错误或疏漏, 敬请见谅.

[English (en)](README.en.md) | [Traditional Chinese (zh-TC)](README.md) | [Simplified Chinese (zh-SC)](README.zh-SC.md)

墨芯是 Windows 的 Rime 前端, 提供 TSF 输入、候选界面、方案部署与配置管理. 整合安装器附通用 RymCp 方案, 可另安装数学、物理、电脑及诗词 DLC.

## 安装与使用

- 从 [Releases](https://github.com/unknownnumbers/rime-stellae/releases) 取得安装器.
- 支持 x64 与 Win32, 包括 x64 Windows 的 32-bit 应用.
- 前端版本为 `0.17.4.61052`. 方案与整合包另记版本.
- 整合方案新装默认 SC 输出, 中文横排 5 项、智能英文直排 6 项, 保留 TC/SC 切换.
- 升级保留用户自定义与学习资料. 同名自定义遮蔽方案默认时, 依 [使用说明](docs/PC.md) 核对与合并.

[方案源码及官方 Weasel 方案](https://github.com/unknownnumbers/RymCp-IME) | [构建](docs/BUILD.md) | [来源](docs/SOURCES.md) | [待办](TODO.md)

本仓库交付前端与整合安装器. 方案功能、可选词汇及乡音复健的后续工作见 RymCp 项目. ARM64、实体键盘及各 Windows 宿主的完整验收仍依已记录的验证范围逐项进行.
